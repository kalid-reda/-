# مشروع الموقع الإلكتروني المتكامل لمؤسسة حدائق الجنة

هذا المشروع يمثل النظام الإلكتروني الرسمي متعدد الصفحات المطور لمؤسسة **حدائق الجنة لتنسيق الحدائق والمساحات الخضراء بالسعودية**.

## 🛠️ تقنيات المشروع
- **UI Architecture:** HTML5, CSS3 CSS Grid & Flexbox.
- **Typography:** Tajawal (Google Fonts).
- **Icons:** FontAwesome v6.4.0.
- **Interactivity:** Custom JavaScript ES6+ (No heavy framework dependencies).
